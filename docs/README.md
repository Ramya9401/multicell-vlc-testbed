# Interactive companion pages

| File | Format |
|---|---|
| `index.html` | IEEE two-column conference-paper layout |
| `explainer.html` | Wide single-column layout, same content |

Both are **self-contained**: no build step, no dependencies, no network calls
apart from Google Fonts. Open either directly in a browser.


## Note on the figures

The interactive panels are the analytical model from the paper, calibrated to
the experimental geometry. Each caption says so. Measured values appear
separately, as measurements, in Tables I and II.
